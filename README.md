# Nertren Law Associates – Next.js site

Requires Node.js 18.17+.

    npm install
    npm run dev      # http://localhost:3000
    npm run build && npm start

Edit content in `app/page.js` (arrays at the top). Styles: `app/globals.css`.
Deploy: push to GitHub and import into Vercel, or run `npm run build && npm start` on your server.
